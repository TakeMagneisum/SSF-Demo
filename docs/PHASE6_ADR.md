# Phase 6 ADR — print reliability, privacy minimization and payload boundaries

Status: implementation with local offline validation; browser/AT/hosted/human acceptance open. Only the supplied Phase 5 demo ZIP used for code/data. No production configuration, provider verification, source-date changes or new geographic data.

## Evidence and design decisions

- Existing direct PDF already lazy-loaded PDFLib (525,099 raw bytes) and embedded Liberation Sans template/metrics/Dawn (146,597 raw bytes). Retain this local architecture rather than introduce a remote service, PDF framework or eager requests. Both requests start in parallel on deliberate Get PDF; dependency promises tracked individually, with load/global checks, timeout and retry. Resolve paths relative to executing script, not current document; old nested finder previously requested nonexistent `find-help/assets/vendor/...` and `find-help/assets/dawn-portait.webp`. Existing QR engine remains eager on full finder pages because selected review needs it. If QR cannot be produced, retain public text and link; PDF failure leaves native print accessible. Generated PDF remains optional; no automatically triggered download or share. Existing Blob URL revoked on repeat, selection/credit/size changes, preview exit and pagehide. Revision guard suppresses stale completions/errors; browser-created copies/open PDF tabs and OS sharing are outside our control. No new third-party runtime assets.
- PDF snapshots still derive solely from sheet title, direct public intro paragraphs, selected articles' h2/p/a, and explicit optional credit. Preserve public title, guide label, scope, source type, urgency flag if supplied, full summary/next, exact contact/address, original URL and guide source-check date plus caveat. Do not interpret contact text as a voice-only number. Both preview and direct PDF get a local, non-persisted large-print choice (11pt normal, 14pt large direct-PDF body; 18pt large heading); wrap long URLs and keep link annotations. Existing glyph subset covers all canonical sheet-field characters tested, including Chilean accents. Unavailable glyphs now cause explicit PDF failure rather than silent substitution. Existing local template is not tagged PDF/PDF-UA; no accessibility compliance assertion. Native print CSS explicitly black-on-white and preserves original full-directory public URL and scoped urgent cards rather than dropping them; private situation input/answer not included. Browser print settings/header/footer and page breaking still require actual verification. No inferred eligibility or new guide check date. Native print has visible alternative and iPhone Share/Print instructions, not a compatibility guarantee. Generic Resource-sheet.pdf and optional original production credit URL retained. QR targets unchanged. No auto-sharing.
- Selection remains ordered JSON-stringified [areaId, resourceId] in existing tab session storage; no new keys. Back/forward-cache restore resynchronizes from current session storage when available; blocked storage preserves in-memory state. Selection clear leaves all other keys. Preview review/back retains focus/scroll; exact pair and order tests use Liberty and London records. Full registry still required by cross-guide catalog and urgent routing; slicing or per-guide lazy fetching is deferred until integrated browser verification, migration compatibility and exact selection parity. Home and map stay metadata-only. Old `assets/find-help.html` duplicate has incomplete registry/handout dependencies and no preview; retain route and document limitation. Root and nested full finder get same print features; dynamic legacy map link now points to root map under project subpath. No redirects or route removal.
- Existing situation form is unnamed and disabled until handler initialization; private search text is page-memory only, not used in PDF, external links or clipboard. Existing legacy incoming `?need=` may already be in host/browser history; the application does not create private query URLs. ZIP remains deliberately shareable and in URL, with policy caveat. The optional resource-suggestion form also had named fields that could enter GET on failed initialization. Remove field names, disable submit until handler installed, read fixed element IDs and show the actual locally prepared note before deliberate copy/download/email. User can still manually enter private info in a suggestion, so prompt for public resource info only and review; deliberate email/share transfers to external provider. No case data in automatic correction links, no private search text in browser history.state written by SSF. No referrer metadata on 42 immutable historic HTML files (41 research guide pages + OPEN-GUIDES); added no-referrer on all 24 editable styled/404 pages. Source scan found no remote script/image/stylesheet/frame/media references in HTML and no editable external target=_blank anchor missing noopener/noreferrer. This is a source audit, not captured network traffic or host policy. External official links, external searches/ZIP, public map destination, mailto/tel, donations and QR actions can disclose the chosen destination or user-reviewed information; no auto-geolocation or telemetry. Browser cache/history/clipboard/OS/monitoring cannot be cleared by SSF. Clear remembered guide/country on privacy page removes only existing two local keys; opening guide can remember it again. Display reset and sheet clear remain independent. No new sensitive state, cookies or URL serialization. Protected static pages cannot receive new policy without explicit baseline change. Privacy disclosures updated to describe current demo behavior; production legal review still required.
- Raw/gzip sums from static referenced files are estimates, not latency, measured transfer or CPU; no actual browser navigation possible under current policy. No real browser traffic/performance claims. Phase 6 only; freeze features for independent QA.

## Rollback

Restore supplied Phase 5 archive atomically; do not regenerate baseline files. If selectively reverting, restore handout/sheet-pdf/guide/area/site scripts and stylesheet/template versions together with cache validator expectations; remove Phase 6 privacy script/control and tests/CI step, retain original records, historical reports, noindex and CNAME safeguards. Use both baseline checks and full suite after rollback. Direct PDF tests exercise generated output and annotations and QR software decoding, not native print, screen-reader interpretation or physical device scan.
