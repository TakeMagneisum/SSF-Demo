A useful directory points you toward options. It cannot guarantee that a provider serves your address or has space, funding, or appointments today.

First-pass educational guide · November 15, 2026

Five different claims

  1. Listed: The resource appears in a directory.
  2. Link working: Its website opened when checked; this does not verify current services.
  3. Officially sourced: Details were compared with an organization or authoritative source on a stated date.
  4. Locally reviewed: A local reviewer has actually confirmed the entry when that status is explicitly shown.
  5. Currently available: The provider confirms availability now; only the responsible organization can determine this for your situation.

Questions to check

  • Does the program serve my ZIP, city, county, age group, or specific circumstances? ZIP codes can overlap county boundaries.
  • Is the program accepting applications, appointments, or referrals now?
  • What are the costs, documents, deadlines, and eligibility rules?
  • Is there a real official number or site where I can verify the next step?
  • Is there an alternate option if this one is unavailable?

A simple call or email script

Before you call or visit has words you can use if you get stuck.

I saw this program listed. Is it currently available in my area, and what is the first step to apply? Which documents would I need?

Find phone numbers and application links through the provider’s official website when possible. Do not send identification or financial records to an unverified contact.

Help improve SSF

If an SSF resource is wrong or outdated, send a correction with the public page link and an authoritative source if available. Reports are reviewed before changes are treated as verified.
